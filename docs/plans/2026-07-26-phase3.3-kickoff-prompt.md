## Lessons carried (L1–L8 stand; new from the 3.2 cycle)

- **L9 (new, the 3.2 branch-review's diagnosis): the SEAM class.** Every whole-branch finding was a per-task fix correcting code + artifact inside its own diff while a same-fact statement one hunk or one doc site away was never re-read. When a fix wave changes a figure or a rule, grep for EVERY statement of it — same file included — in the same commit.
- **L10 (new): the spec outranks the dispatch brief.** A brief's gloss contradicted spec §4's keying rule; the implementer followed the spec, flagged it, and was right. Implementers resolve brief-vs-spec toward the spec and flag; reviewers adjudicate from the authority text.
- **L11 (new): deviations-with-grounds + close-out fold-back works.** Six recorded deviations (ArenaAgent signature, difftest defended arm, single-draw collapse, χ²-vs-binomial bands, smoke N, both-arms) were each recorded at decision time and folded back into the spec at T13 — none re-litigated. Keep the discipline.
- **L12 (new): compile-time pins beat runtime asserts where possible** (`const { assert!(...) }`; exhaustive matches; view-only-by-signature) — the strongest honesty properties on the branch are the ones the type system carries.
