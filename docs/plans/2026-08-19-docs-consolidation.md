Docs-only: no code, no tests, no `SEMANTICS_REV` implication.

**The governing invariant: every deleted FACT exists somewhere pointed-to.** Deletion means relocation-with-pointer, never loss — this pass reorganizes the library; it does not burn books. The Fable review pass before merge has exactly one job: diff-walk the removals and verify each fact's new home resolves. This document is that review's checklist and the durable record of where everything went.

**Method.** Whole-file rewrites, never mid-file anchor surgery (the Phase-C doc-edit failure mode); every verbatim move done by line-number `sed` extraction from the pre-pass originals and **diff-verified byte-identical**; the appendices below are `sed`-extracted the same way, inside `text` fences, from `CLAUDE.md` as of master `181e61d`. Token figures are estimated as bytes ÷ 2.5, calibrated against the owner's ~41k reading for the 103,373-byte pre-pass CLAUDE.md; both raw bytes and the estimate are recorded so the estimator can be re-derived.
