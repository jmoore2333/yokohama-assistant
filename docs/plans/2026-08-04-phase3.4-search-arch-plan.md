## Task-order rationale & risks

T0 before any seam edit (golden discipline). T1 before T2/T3 because the capped-S1 is both an experiment arm and the screening opponent, and its counters define the meter contract MCTS implements against. T5 after T4 so the seam lands with the full tally surface in one pass (golden churn once). T8 strictly before T9 (pre-registration). The known heavy-tail risk: capped cells at Placement roots — T1's value-ordered allocation is the designed mitigation, and its degeneracy pin is the tripwire. Compute stays modest (§5: order an hour for the registered table + screening).
