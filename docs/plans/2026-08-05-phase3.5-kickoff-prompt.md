## Lessons (L1–L26 stand in the ledgers; NEW from the 3.4 cycle)

- **L27 — inline the constants in orchestration scripts.** The Workflow `args` global reached a task script as `undefined` once; the HEAD-guard caught it (an implementer briefed with `undefined` must STOP, and did). Per-task scripts carry task id + expected HEAD as literals.
- **L28 — WIP capture-preservation commits make pauses free.** An owner pause interrupted the experiment between its cells and its adjudication; committing the verbatim captures (with the drawn OS-entropy master preserved) kept the attempt count at one and cost only wall-clock.
- **L29 — write fix-wave commit messages against the DIFF, not the intent.** One fix-wave message described five edits while its diff carried four; the fifth landed in a follow-up with the discrepancy recorded. Read `git diff --staged` before writing the message.
- **L30 — mutation-probing review lenses need isolated worktrees.** A lens's transient golden failure was another lens's concurrent mutation; the adjudicator falsified the "nondeterminism" reading by reproduction. Parallel reviewers who mutate must not share a tree.
- **L31 — per-task stuck alarms with progress diagnostics.** A 1-hour monitor per dispatched task (fires on genuine return, else prints journal/tree state) turns "is it stuck?" into an evaluate-don't-kill decision; the T3 alarm correctly let an active long task continue.
- **Also validated end-to-end:** the L19 shape at full scale (a totally-pre-registered rule + immutable addendum survived an interruption, an adjudication, and three independent re-derivations); the last-legitimate-moment fix window for pre-registration documents (fix accounting BEFORE the first registered cell, never after).
