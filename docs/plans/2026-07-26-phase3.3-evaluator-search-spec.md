- **Arm 2 — the fresh-entropy confirmation (BINDING, the lens-1 multiplicity repair):** at the 3.3 close, the same cell at the same N runs once on an **OS-entropy master, drawn and committed with the run**; the gate is DECLARED met only if BOTH arms pass. Arm 1's master stays fixed (its role is regression); **arm 2 draws a FRESH OS-entropy master per attempt** — a fresh sample is not master shopping, and it is what prevents fitting to 200 frozen seeds (under a frozen master alone, k re-attempts of a null bot compound a ~2.5% one-sided pass rate; ledger row 16's 19.0%-type-I hazard is exactly this shape).
