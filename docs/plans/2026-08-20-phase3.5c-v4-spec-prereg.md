## 5. The feasibility benchmark

### 5.1 Conventions

- **A PAIR** = two constructed legal positions (fixture-built states rendered to views;
  `Rules::standard()` unless the registration names a hand-constructed layout) with:
  a declared GREATER SIDE (named FIRST in every registration; `Δv = greater − lesser`),
  a declared STAGE ENDPOINT per registered row (p = 0 or p = PROGRESS_FULL_PPM;
  endpoint-exact under `interpolate`, so every row is linear in one stage vector; a
  both-endpoints pair contributes one row to each system), a declared VIEW CLASS
  (HAND-OFF default; MID-TURN pairs name their `TurnPhase` and whether mercenary), and
  a declared MARGIN CLASS. **STAGE and VIEW CLASS are independent declarations, both
  required.**
- **Fixture declarations (every pair):** both sides non-terminal
  (`terminal_standing_of == None`, asserted); `progress_ppm` printed, equal across sides
  and to the declaration; **BOTH seats' president locations declared — DEFAULT: both
  InHand unless the registration states otherwise** (the acting-class pairs
  2(a)/4(f)/6(d)/11 place the actor's president at the acted area by construction;
  1(c)/1(e)/8 declare their own; a hand-off-class fixture may not place a seat's own
  president on an area where that seat holds assistants — unreachable post-Recovery,
  Telephone excepted; an opponent-president area in a fixture is declared, since it
  blocks S7-counting and taxes placement);
  achievement DRAWS declared (setup always draws exactly one Category-A card — "no
  goods achievement" is not a legal state); TECH ownership declared (3(a)/3(b) exclude
  System of Stock, Textile/Spinning Mill, University — each changes the marginal the
  pair calibrates); the full 31-feature delta printed with the EXPECTED-NONZERO ROWS
  listed per registration (an unlisted nonzero row at run time is a fixture defect —
  sanctioned to fix and re-freeze before covered results).
- **Stage realization at 2P, all four clocks** (`progress_ppm` = max of deck, church,
  customs, building clocks): p = 0 requires a FULL deck (no port take ever — hands
  capped at the dealt starting order), ZERO real pawns on both tracks (either seat), and
  ZERO buildings; p = FULL is constructed via deck saturation (deck empty, port full or
  the trigger declared) so that track/building deltas inside a pair are absorbed by the
  max — the construction each late pair names.
- **The pinned scale and margin classes.** The solve pins `w_vp = (1, 40)` (V2's shipped
  pair, eval.rs:853–855) as equalities. MARGINED = a registered INTEGER
  `max(1, ceil(margin_vp × w_vp(stage)))` with a NAMED CARRIER; the good/yen carriers
  are **AMORTIZED terminal rates** (`money/2`, `goods_sum/3` are integer floors —
  scoring.rs:341–357 — so a single unit realizes 0-or-1, never ⅓/½; no pair may cite a
  realized terminal delta as its carrier's evidence), and access margins (1(a), 3(c))
  embed a REALIZATION-PROBABILITY-1 assumption, named in the Part-B core-inspection
  checklist as a candidate margin cause. DIRECTION-ONLY = 1. WEAK = 0. **The early floor
  is a STRENGTHENING** (⅓-VP → 1 is 3×; ½-VP → 1 is 2×): early MARGINED ≡
  DIRECTION-ONLY in force, and §5.4's early-stage rescale diagnostic exists because an
  early-only infeasibility may be integer granularity. The same integers are step 9's
  inequalities.
- **Known forced collaterals** (registered once): a goods change moves O2 and any live
  matching leg; order fulfillment moves E2 (−3..−6), O5 (recompute), may queue
  choices (movement 2/36, warehouse 5/36 — the any-good face is unreachable from
  orders), and awards a mercenary ONLY at an even pre-fulfillment icon count for the
  card's country with that country's finite shared supply (3/2/2/2/1) non-zero — 6(a)
  registers both facts; track placements queue `ChurchSpace`/`CustomsSpace` when ≥ 2
  spaces qualify, and the majority mirror moves non-monotonically with the chosen space

### 5.4 Part B — the bounded compatibility solve

**Arithmetic model.** Integer weights, box |w| ≤ 64; `w_vp = (1, 40)` pinned as
equalities; the V2 hand ordering (`core > on_board`, `on_board > excess`, both vectors)
as strict inequalities; every registered row `Σ_f w_f(stage)·Δv_f ≥ margin` at its
endpoint. **The system DECOMPOSES: no constraint couples the stages** (every row binds
one endpoint vector; `interpolate` is endpoint-exact) — witness search, oracle, and
minimization run PER STAGE over 31 variables (30 free after the pin). Registered
per-stage row counts derive mechanically from §5.2's stage column (a both-endpoints
pair contributes one row to each; this registry yields **EARLY: 23 pair rows + 2
orderings + 1 pin · LATE: 26 + 2 + 1** — both-endpoints 18 {1(a–e), 3(a–c), 4(b), 4(c),

{2(a), 4(d), 4(f), 6(d)×2, 7, 8, 11(e)}); the solver artifact prints its realized counts
as a cross-check and a mismatch is a registry defect, not a result.

**(1) Witness search (per stage):** total violation
`Σ_c max(0, margin_c − Σ_f w_f·Δv_f(c))` in integer units; deterministic coordinate
descent, **init = V2-padded** (incumbents at V2, candidates 0), coordinate order =
`Feature::ALL` order (the tie-break's "listed order"); at each coordinate try ALL of
{±16, ±8, ±4, ±2, ±1}, take the best strict decrease, ties toward smaller |w| then
listed order; a full no-improvement sweep ends the search; ≤ 32 sweeps. Zero violation
= a witness; feasibility PROVEN. **Reporting:** the artifact prints, per stage, the
binding-constraint count K (slack 0 at the witness), the slack profile, and the count
of constraints implied by the rest (drop-one re-test) — a SAT is read as "no
contradiction among the K binding constraints," never unqualified compatibility (the
system is underdetermined by design: 23–26 rows vs 30 free).

branch-and-bound over the integer box. Arithmetic = i128 rationals with CHECKED
operations, gcd-reduced; ANY overflow aborts to INCONCLUSIVE (never UNSAT). Prune rule
= PROVEN rational-relaxation infeasibility of the sub-box, established by exact
Fourier–Motzkin or exact simplex with Bland's rule. Budget (registered, DETERMINISTIC — node count only, no wall clock, per the
per-machine-figures discipline): 10⁷ nodes per stage system; exhaustion = INCONCLUSIVE, routed to the owner — "the
