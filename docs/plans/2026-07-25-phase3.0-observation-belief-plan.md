**Spec:** `docs/plans/2026-07-25-phase3.0-observation-belief-spec.md` (v2.1, clean-eyes-reviewed) · **Map:** `docs/plans/2026-07-25-phase3-map.md` §5 "3.0" · **Branch:** `phase3.0-observation-belief` · **Base:** master `63f7045`, SEMANTICS_REV 3

**Goal:** Give the engine a typed, seat-relative observation (`PlayerView`), a belief sampler that reconstructs full `GameState`s consistent with an observation, and an honest-agent surface that structurally cannot see hidden state — proven by standing leakage and conservation suites.

**Architecture:** Pure read-side addition. `observe(&GameState, seat) -> PlayerView` masks the five hidden members by *exhaustive destructure* (a new state field becomes a compile error, never a silent leak). `BeliefSampler::from_view(&PlayerView, &Rules, seed)` draws uniform worlds satisfying conservation, which the real engine then plays (sound: legality is view-measurable). `HonestAgent` takes views and legal moves — never a `GameState` — and `run_honest_game` builds agents through a factory *inside* the driver so nothing omniscient can be handed in from outside.

**Tech Stack:** Rust (stable), `serde`/`serde_json`, `rand_chacha::ChaCha8Rng` — all already `[dependencies]` of `yokohama-core`. No new crates, no new Cargo entries.

```rust
//! Seat-relative observation of a game (Phase 3.0).
//!
//! A `PlayerView` is what ONE seat may legitimately see. It is produced only
//! by `game::observe::observe`, which masks the five hidden members
//! (`order_deck` order, `tech_deck` order, `orders_removed` contents,
//! opponents' unfulfilled starting orders, and the setup seed). Bots take
//! views, never `GameState` -- that is the honesty boundary of the whole
//! computer-player ladder.
//!
//! This module is PURE DATA: no `crate::game` imports, no `&Rules` methods,
//! no hashing (the `&Rules` pool helpers live in `game::observe`, and
//! `view_digest` beside `state_digest` in `game::semantics`).

use serde::{Deserialize, Serialize};

use crate::types::{
    AchievementCard, AdditionalActionState, AreaId, BoardLayout, ChurchTrack, CustomsTrack,
    EndGameTrigger, LabState, MercenaryState, MercenarySupply, OrderCardId, PendingChoice,
    PlayerColor, PlayerId, PortState, PresidentLocation, AssistantState, ShophouseState,
    TechCardId, TradingHouseState, TurnPhase,

/// One entry of a seat's visible hand: either a card whose identity is public
/// (every Port take is witnessed by the whole table --
/// `analysis-1/yokohama-kb/01-rules-reference.md:703`) or the one slot holding
/// an unfulfilled starting order, whose identity is not.

    HiddenStartingOrder,
}

    pub player_colors: Vec<PlayerColor>,

/// Why a seat view could not be derived.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ViewError {
    /// `PlayerId::DUMMY` is a track-slot sentinel with no `PlayerState`.
    DummySeat,
    SeatOutOfRange(PlayerId),
    /// The viewer's own starting-order deal was never recorded (a live
    /// `Unknown` on the viewer's own seat). A seat cannot be unknown to
    /// itself: such a state is a tracking artifact, not a seat view.
    ViewerDealUnrecorded(PlayerId),
    CorruptState(&'static str),
}

impl std::fmt::Display for ViewError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            ViewError::DummySeat => write!(f, "PlayerId::DUMMY is not a seat and has no view"),
            ViewError::SeatOutOfRange(p) => write!(f, "seat {} is not in this game", p.0),
            ViewError::ViewerDealUnrecorded(p) => write!(
                f,
                "seat {}'s own starting-order deal was never recorded; it cannot view itself",
                p.0
            ),
            ViewError::CorruptState(msg) => write!(f, "state is not viewable: {msg}"),
        }
    }
}

impl std::error::Error for ViewError {}
```

```rust
//! `observe`: derive one seat's `PlayerView` from a `GameState` (Phase 3.0).
//!
//! # The destructure rule (load-bearing, do not "simplify")
//!
//! Every state struct is destructured EXHAUSTIVELY here -- every field named,
//! never `..`, never functional-update syntax (`GameState { x, ..other }`).
//! That is what makes adding a state field a COMPILE ERROR
//! (`error[E0027]: pattern does not mention field`) instead of a silent
//! information leak. Functional-update syntax passes new fields through
//! unclassified, which is the exact failure this whole sub-phase exists to
//! prevent. A field that is deliberately dropped is bound and commented.
//!
//! The five hidden members (spec §1, verified 2026-07-25):
//!   1. `config.setup_seed`  -- regenerates deck, box, board AND every deal
//!   2. `order_deck` order   -- size only survives
//!   3. `tech_deck` order    -- size only survives
//!   4. `orders_removed` contents -- derived size only
//!   5. each opponent's UNFULFILLED starting order, at both storage sites

use crate::game::rules::Rules;
use crate::types::{
    GameConfig, GameState, HandCard, OrderCardId, PlayerId, PlayerState, PlayerView, TechCardId,
    ViewConfig, ViewError, VisiblePlayer,
};

pub fn observe(state: &GameState, seat: PlayerId) -> Result<PlayerView, ViewError> {
    if seat.is_dummy() {
        return Err(ViewError::DummySeat);
    }
    let seat_idx = seat.0 as usize;
    if seat_idx >= state.players.len() {
        return Err(ViewError::SeatOutOfRange(seat));
    }
    if state.players[seat_idx].starting_order_hidden {
        return Err(ViewError::ViewerDealUnrecorded(seat));
    }

    // EXHAUSTIVE -- see the module docs before touching this pattern.
    let GameState {
        config,
        board_layout,
        players,
        current_player,
        turn_phase,
        turn_number,
        additional_action_state,
        current_action_power,
        is_mercenary_action,
        mercenary_target_area,
        mercenary_return_phase,
        president_start_area,
        port_state,
        lab_state,
        order_deck,
        tech_deck,
        orders_removed,
        church_track,
        customs_track,
        achievements,
        mercenary_supply,
        station_location,
        end_game_triggered,
        trigger_reason,
        final_round,
        trigger_player,
        pending_choices,
    } = state;

    // EXHAUSTIVE. `setup_seed` is hidden member 1: dropped, never copied.
    let GameConfig {
        player_count,
        player_colors,
        start_player,
        has_port_b,
        has_lab_b,
        setup_seed: _,
    } = config;

    // The live `Unknown` fiction parks BOTH dealt cards in `orders_removed`
    // (game/setup.rs:254-258), so the engine's pile is one larger per hidden
    // seat than the physical box. The view publishes the PHYSICAL count.
    let hidden_seats = players.iter().filter(|p| p.starting_order_hidden).count();
    let orders_removed_len = orders_removed
        .len()
        .checked_sub(hidden_seats)
        .ok_or(ViewError::CorruptState(
            "more hidden-deal seats than cards in the removed pile",
        ))?;

    let visible: Vec<VisiblePlayer> = players.iter().map(|p| visible_player(p, seat)).collect();

    Ok(PlayerView {
        viewer: seat,
        config: ViewConfig {
            player_count: *player_count,
            player_colors: player_colors.clone(),
            start_player: *start_player,
            has_port_b: *has_port_b,
            has_lab_b: *has_lab_b,
        },
        board_layout: board_layout.clone(),
        players: visible,
        current_player: *current_player,
        turn_phase: *turn_phase,
        turn_number: *turn_number,
        additional_action_state: additional_action_state.clone(),
        current_action_power: *current_action_power,
        is_mercenary_action: *is_mercenary_action,
        mercenary_target_area: *mercenary_target_area,
        mercenary_return_phase: *mercenary_return_phase,
        president_start_area: *president_start_area,
        port_state: port_state.clone(),
        lab_state: lab_state.clone(),
        order_deck_len: order_deck.len(),
        tech_deck_len: tech_deck.len(),
        orders_removed_len,
        church_track: church_track.clone(),
        customs_track: customs_track.clone(),
        achievements: achievements.clone(),
        mercenary_supply: mercenary_supply.clone(),
        station_location: *station_location,
        end_game_triggered: *end_game_triggered,
        trigger_reason: *trigger_reason,
        final_round: *final_round,
        trigger_player: *trigger_player,
        pending_choices: pending_choices.clone(),
    })
}

fn visible_player(p: &PlayerState, viewer: PlayerId) -> VisiblePlayer {
    // EXHAUSTIVE -- see the module docs.
    let PlayerState {
        id,
        color,
        victory_points,
        president_location,
        assistants,
        shophouses,
        trading_houses,
        money,
        copper,
        silk,
        tea,
        seafood,
        imported_goods,
        order_cards_in_hand,
        starting_order,
        starting_order_hidden,
        completed_orders,
        technologies,
        five_power_tokens,
        mercenaries,
        church_positions,
        customs_positions,
    } = p;
```

```rust
impl PlayerView {
    /// How many hidden starting-order slots this view carries (one per
    /// opponent whose starting order is still unfulfilled).
    pub fn hidden_slot_count(&self) -> usize {
        self.players
            .iter()
            .flat_map(|p| p.hand.iter())
            .filter(|c| **c == HandCard::HiddenStartingOrder)
            .count()
    }

    /// Every order card this seat cannot locate: the registry minus the
    /// face-up Port displays, minus every known hand card, minus every
    /// completed order. Ascending by id -- the registries are `HashMap`-backed
    /// and their iteration order is process-randomized, which would make a
    /// seeded sampler irreproducible ACROSS PROCESSES (silently).
    pub fn unseen_orders(&self, rules: &Rules) -> Vec<OrderCardId> {
        let mut located: Vec<OrderCardId> = Vec::new();
        for slot in self.port_state.port_a.slots.iter().flatten() {
            located.push(*slot);
        }
        if let Some(b) = &self.port_state.port_b {
            for slot in b.slots.iter().flatten() {
                located.push(*slot);
            }
        }
        for p in &self.players {
            for c in &p.hand {
                if let HandCard::Known(id) = c {
                    located.push(*id);
                }
            }
            located.extend(p.completed_orders.iter().copied());
        }
        rules
            .orders
            .iter_sorted_by_id()
            .into_iter()
            .map(|c| c.id)
            .filter(|id| !located.contains(id))
            .collect()
    }

    /// The exact multiset of technologies still in the deck: no tech card is
    /// ever removed at setup, so `30 - labs - owned` is EXACT and only the
    /// permutation is unknown. Ascending by id, same reason as above.
    pub fn tech_deck_remainder(&self, rules: &Rules) -> Vec<TechCardId> {
        let mut located: Vec<TechCardId> = Vec::new();
        for slot in self.lab_state.lab_a.slots.iter().flatten() {
            located.push(*slot);
        }
        if let Some(b) = &self.lab_state.lab_b {
            for slot in b.slots.iter().flatten() {
                located.push(*slot);
            }
        }
        for p in &self.players {
            located.extend(p.technologies.iter().copied());
        }
        rules
            .techs
            .iter_sorted_by_id()
            .into_iter()
            .map(|c| c.id)
            .filter(|id| !located.contains(id))
            .collect()
    }
}
```

```rust
/// Stable content digest of a `PlayerView` -- the OBSERVATION identity the
/// leakage suites compare on. Same FNV-1a-64-over-canonical-JSON recipe as
/// `state_digest` and sound for the same reason: a `PlayerView`'s maps are
/// all `BTreeMap`s (it copies only `BTreeMap`-bearing state types), so serde
/// emits them in key order.
///

/// two worlds a seat cannot tell apart get different state digests.
pub fn view_digest(view: &crate::types::PlayerView) -> String {
```

```rust
//! `BeliefSampler`: draw full `GameState`s consistent with one seat's
//! `PlayerView` (Phase 3.0 determinization).
//!
//! v1 contract: CONSERVATION + CONSISTENCY, uniform. Every unseen order card
//! is equally likely to be anywhere it could be; the tech deck is a uniform
//! permutation of an exactly-known remainder. Posterior FIDELITY (which of
//! two dealt cards an opponent chose to keep is a PREFERENCE, not chance --
//! rulebook p.4 step 12) is a measured v2 refinement, deliberately deferred:
//! an unfulfilled order carries zero terminal-score weight (game/scoring.rs
//! reads `completed_orders` only), so mis-sampling one costs nothing at
//! evaluation, only in opponent-action prediction.
//!
//! CARRY-FORWARD LIMIT (spec L3): a sampled world is NOT safe to roll forward
//! across an observed Port/Lab refill -- a refill publicly reveals a deck card
//! (game/cards.rs:230, :266), so a search must re-sample or condition after
//! each one.
//!
//! Like `game::observe`, world construction here uses FULL struct literals
//! (neither `GameState` nor `PlayerState` implements `Default`), so a new
//! state field is a compile error here too. Never build a world by cloning a
//! true `GameState` and patching it -- that reintroduces the leak this whole
//! module exists to prevent.

use rand::seq::SliceRandom;
use rand::SeedableRng;
use rand_chacha::ChaCha8Rng;

use crate::game::rules::Rules;
use crate::types::{
    GameConfig, GameState, HandCard, OrderCardId, PlayerId, PlayerState, PlayerView, TechCardId,
};

/// Why a view cannot be sampled from.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum BeliefError {
    /// The view's published sizes do not reconcile with its unseen pool.
    Inconsistent(String),
    /// Materializing this seat's hidden starting order would exceed the
    /// 3-card hand limit.
    HandOverflow(PlayerId),
    /// A card in the view is not in the registry (or the registry is not the
    /// standard 36/30).
    RegistryMismatch(String),
}

impl std::fmt::Display for BeliefError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            BeliefError::Inconsistent(m) => write!(f, "view does not reconcile: {m}"),
            BeliefError::HandOverflow(p) => {
                write!(f, "seat {}'s hidden card would exceed the 3-card hand limit", p.0)
            }
            BeliefError::RegistryMismatch(m) => write!(f, "registry mismatch: {m}"),
        }
    }
}

impl std::error::Error for BeliefError {}

/// Samples worlds consistent with one seat's observation.
pub struct BeliefSampler {
    view: PlayerView,
    unseen_orders: Vec<OrderCardId>,
    tech_remainder: Vec<TechCardId>,
    /// (player index, hand index) of each masked slot, ascending.
    hidden_slots: Vec<(usize, usize)>,
    rng: ChaCha8Rng,
}

impl BeliefSampler {
    pub fn from_view(view: &PlayerView, rules: &Rules, seed: u64) -> Result<Self, BeliefError> {
        let unseen_orders = view.unseen_orders(rules);
        let tech_remainder = view.tech_deck_remainder(rules);

        let mut hidden_slots: Vec<(usize, usize)> = Vec::new();
        for (pi, p) in view.players.iter().enumerate() {
            for (hi, c) in p.hand.iter().enumerate() {
                if *c == HandCard::HiddenStartingOrder {
                    if p.hand.len() > 3 {
                        return Err(BeliefError::HandOverflow(p.id));
                    }
                    hidden_slots.push((pi, hi));
                }
            }
        }

        if tech_remainder.len() != view.tech_deck_len {
            return Err(BeliefError::RegistryMismatch(format!(
                "tech remainder {} != published deck size {}",
                tech_remainder.len(),
                view.tech_deck_len
            )));
        }
        let need = view.order_deck_len + view.orders_removed_len + hidden_slots.len();
        if unseen_orders.len() != need {
            return Err(BeliefError::Inconsistent(format!(
                "unseen pool {} != deck {} + box {} + hidden slots {}",
                unseen_orders.len(),
                view.order_deck_len,
                view.orders_removed_len,
                hidden_slots.len()
            )));
        }

        Ok(Self {
            view: view.clone(),
            unseen_orders,
            tech_remainder,
            hidden_slots,
            rng: ChaCha8Rng::seed_from_u64(seed),
        })
    }

    /// One world consistent with the observation. Cheap enough to call per
    /// search node (a clone plus two shuffles).
    pub fn sample(&mut self) -> GameState {
        let mut pool = self.unseen_orders.clone();
        pool.shuffle(&mut self.rng);
        let deck_len = self.view.order_deck_len;
        let order_deck: Vec<OrderCardId> = pool[..deck_len].to_vec();
        let hidden: Vec<OrderCardId> = pool[deck_len..deck_len + self.hidden_slots.len()].to_vec();
        let mut orders_removed: Vec<OrderCardId> =
            pool[deck_len + self.hidden_slots.len()..].to_vec();
        // Rules-inert contents: canonicalize so two behaviourally identical
        // worlds are the same state. (`OrderCardId` has no `Ord`.)
        orders_removed.sort_by_key(|c| c.0);

        let mut tech_deck = self.tech_remainder.clone();
        tech_deck.shuffle(&mut self.rng);

        let mut players: Vec<PlayerState> =
            self.view.players.iter().map(materialize_player).collect();
        for ((pi, hi), card) in self.hidden_slots.iter().zip(hidden) {
            players[*pi].order_cards_in_hand[*hi] = card;
            players[*pi].starting_order = Some(card);
        }

        let v = &self.view;
        GameState {
            config: GameConfig {
                player_count: v.config.player_count,
                player_colors: v.config.player_colors.clone(),
                start_player: v.config.start_player,
                has_port_b: v.config.has_port_b,
                has_lab_b: v.config.has_lab_b,
                // A sampled world is a FICTION. 0 means "not seed-generatable":
                // never hand one to GameRecord/replay as if it were a real game.
                setup_seed: 0,
            },
            board_layout: v.board_layout.clone(),
            players,
            current_player: v.current_player,
            turn_phase: v.turn_phase,
            turn_number: v.turn_number,
            additional_action_state: v.additional_action_state.clone(),
            current_action_power: v.current_action_power,
            is_mercenary_action: v.is_mercenary_action,
            mercenary_target_area: v.mercenary_target_area,
            mercenary_return_phase: v.mercenary_return_phase,
            president_start_area: v.president_start_area,
            port_state: v.port_state.clone(),
            lab_state: v.lab_state.clone(),
            order_deck,
            tech_deck,
            orders_removed,
            church_track: v.church_track.clone(),
            customs_track: v.customs_track.clone(),
            achievements: v.achievements.clone(),
            mercenary_supply: v.mercenary_supply.clone(),
            station_location: v.station_location,
            end_game_triggered: v.end_game_triggered,
            trigger_reason: v.trigger_reason,
            final_round: v.final_round,
            trigger_player: v.trigger_player,
            pending_choices: v.pending_choices.clone(),
        }
    }
}

/// A `VisiblePlayer` back to a `PlayerState`. Masked hand slots are filled
/// with a placeholder that `sample` immediately overwrites -- keeping hand
/// LENGTH and every other index exactly as observed.
fn materialize_player(p: &crate::types::VisiblePlayer) -> PlayerState {
    let order_cards_in_hand: Vec<OrderCardId> = p
        .hand
        .iter()
        .map(|c| match c {
            HandCard::Known(id) => *id,
            HandCard::HiddenStartingOrder => OrderCardId(0), // overwritten by `sample`
        })
        .collect();
    PlayerState {
        id: p.id,
        color: p.color,
        victory_points: p.victory_points,
        president_location: p.president_location,
        assistants: p.assistants.clone(),
        shophouses: p.shophouses.clone(),
        trading_houses: p.trading_houses.clone(),
        money: p.money,
        copper: p.copper,
        silk: p.silk,
        tea: p.tea,
        seafood: p.seafood,
        imported_goods: p.imported_goods,
        order_cards_in_hand,
        starting_order: p.starting_order,
        // Samples are always Keep-shaped: the card is materialized, so nothing
        // about this world is "unrecorded".
        starting_order_hidden: false,
        completed_orders: p.completed_orders.clone(),
        technologies: p.technologies.clone(),
        five_power_tokens: p.five_power_tokens,
        mercenaries: p.mercenaries.clone(),
        church_positions: p.church_positions.clone(),
        customs_positions: p.customs_positions.clone(),
    }
}
```

```rust
//! The honest-agent surface (Phase 3.0): what a bot is allowed to see.
//!
//! `HonestAgent`'s method signatures are the honesty boundary. They cannot
//! name `GameState` or `PendingSetup`, so a bot CANNOT read the deck order,
//! the boxed pile, an opponent's hidden starting order, or the setup seed --
//! not by discipline, by types.
//!
//! Scope, stated honestly (spec §3.5):
//!   * per-decision channel -- closed by these signatures;
//!   * construction channel -- closed HERE by `run_honest_game` building
//!     agents through a factory it invokes itself, after `new_game`, passing
//!     only `(seat, player_count)`. An agent handed a `GameRecord` outside the
//!     driver would still see everything (a record carries `seed` + `choices`),
//!     which is why "bots never receive records" is a review-enforced rule;
//!   * coalition channel -- two agents sharing state via `Rc`/`Arc` pool their
//!     views. Documented, not prevented.
//!
//! SEED HYGIENE (spec §1-B / L7, binding for real evaluation): `new_game`'s
//! board is generated from the setup seed BEFORE the deck is shuffled, so the
//! public board is an injective fingerprint of that seed -- small sequential
//! seeds are brute-forceable in milliseconds, recovering the entire hidden
//! set. Any driver evaluating agents for real (3.2's arena, any strength
//! claim) MUST draw its game seeds uniformly over the full u64 and RECORD
//! them. Honesty-suite tests use small fixed seeds deliberately: their agents
//! are not adversarial, and the residual is proven executable by the
//! seed-recovery red-team test instead.

use std::collections::HashMap;

use rand::Rng;
use rand::SeedableRng;
use rand_chacha::ChaCha8Rng;

use crate::game::apply_move::apply_move_unchecked;
use crate::game::belief::BeliefSampler;
use crate::game::end_game::is_game_over;
use crate::game::invariants::check_invariants;
use crate::game::legal_moves::get_legal_moves;
use crate::game::observe::observe;
use crate::game::rules::Rules;
use crate::game::scoring::{final_result, GameResult};
use crate::game::setup::{finalize_setup, new_game, StartingOrderChoice};
use crate::types::{
    EndGameTrigger, GameConfig, Move, OrderCardId, PlayerId, PlayerView, TurnPhase,
};

/// Non-termination guard, deliberately the same value as the fuzz driver's
/// `MAX_TURNS` (`crates/yokohama-core/tests/common/mod.rs:43`): uniform-random
/// play wanders (observed max 6036 turns at 2P seed 191), and the two loops
/// must not disagree about what "stuck" means.
pub const HONEST_MAX_TURNS: u32 = 10_000;

/// A player that acts only on what its seat may legitimately see.
pub trait HonestAgent {
    /// Setup: choose which of the two dealt Order cards to keep (index 0 or
    /// 1). The agent sees ONLY its own deal -- `PendingSetup` carries every
    /// seat's cards and the seeded deck, so the driver never passes it.
    fn choose_starting_order(&mut self, seat: PlayerId, deal: &[OrderCardId; 2]) -> u8;

    /// Play: choose one of `legal`.
    ///
    /// Being handed the engine's own legal list is leak-free for Keep-shaped
    /// states: legality is a pure function of the acting seat's legitimate
    /// view (verified exhaustively and by the independent oracle; pinned
    /// forever by the view-measurability suite). It is NOT true for a live
    /// `Unknown` seat, whose tracked hand under-counts by one -- see spec L8.
    fn choose_move(&mut self, view: &PlayerView, legal: &[Move], rules: &Rules) -> Move;
}

/// The 3.0 gate's agent: keeps a random card, then samples ONE world from its
/// view and picks uniformly from that world's legal moves.
pub struct TrivialHonestAgent {
    rng: ChaCha8Rng,
}

impl TrivialHonestAgent {
    pub fn new(seed: u64) -> Self {
        Self { rng: ChaCha8Rng::seed_from_u64(seed) }
    }
}

impl HonestAgent for TrivialHonestAgent {
    fn choose_starting_order(&mut self, _seat: PlayerId, _deal: &[OrderCardId; 2]) -> u8 {
        self.rng.gen_range(0..2u8)
    }

    fn choose_move(&mut self, view: &PlayerView, legal: &[Move], rules: &Rules) -> Move {
        // The sampler seed comes from THIS AGENT'S OWN RNG stream and nothing
        // else. Deriving it from any state-flavoured value (`state_digest`
        // hashes the hidden members) would correlate the sample with the truth
        // it must be blind to.
        let sampler_seed: u64 = self.rng.gen();
        if let Ok(mut sampler) = BeliefSampler::from_view(view, rules, sampler_seed) {
            let world = sampler.sample();
            let world_legal = get_legal_moves(&world, rules);
            if !world_legal.is_empty() {
                let pick = world_legal[self.rng.gen_range(0..world_legal.len())].clone();
                // Roll the sampled world forward by the chosen move: the one
                // load-bearing use of a sample in 3.0, and exactly what 3.3's
                // search will do with it.
                debug_assert!(
                    apply_move_unchecked(&world, &pick, rules).is_ok(),
                    "a move drawn from a sampled world's own legal list must apply in it"
                );
                if legal.contains(&pick) {
                    return pick;
                }
            }
        }
        // Fall back to the true legal list (equal to the sampled one for
        // Keep-shaped states; a live `Unknown` seat is the documented L8 case).
        legal[self.rng.gen_range(0..legal.len())].clone()
    }
}

/// Outcome of one honest game. Deliberately carries NO terminal `GameState`:
/// a terminal state holds the whole hidden set, and a stats struct in a
/// caller's hands is one convenience method away from an agent's memory.

#[derive(Debug, Clone)]
pub struct HonestGameStats {
    pub seed: u64,
    pub players: u8,
    pub turns: u32,
    pub moves_applied: u64,
    pub trigger: Option<EndGameTrigger>,
    pub result: GameResult,
    pub branching_by_phase: HashMap<TurnPhase, (u64, u64)>,
}

/// Play one full game with one `HonestAgent` per seat.
///
/// `make_agent` is invoked BY THIS FUNCTION, after `new_game`, with only
/// `(seat, player_count)` — the caller never gets a chance to construct an
/// agent from privileged setup data.
pub fn run_honest_game(
    seed: u64,
    players: u8,
    rules: &Rules,
    make_agent: &mut dyn FnMut(PlayerId, u8) -> Box<dyn HonestAgent>,
) -> Result<HonestGameStats, String> {
    let pending = new_game(GameConfig::for_player_count(players), rules, seed)
        .map_err(|e| format!("new_game failed (seed {seed}, {players}P): {e}"))?;

    let mut agents: Vec<Box<dyn HonestAgent>> =
        (0..players).map(|i| make_agent(PlayerId(i), players)).collect();

    let mut choices: Vec<StartingOrderChoice> = Vec::with_capacity(players as usize);
    for (i, agent) in agents.iter_mut().enumerate() {
        let seat = PlayerId(i as u8);
        let deal = pending.deals[i];
        let keep = agent.choose_starting_order(seat, &deal);
        if keep > 1 {
            return Err(format!(
                "seat {} returned keep index {keep}: must be 0 or 1 (seed {seed}, {players}P)",
                seat.0
            ));
        }
        choices.push(StartingOrderChoice::Keep(keep));
    }

    let mut state = finalize_setup(pending, &choices)
        .map_err(|e| format!("finalize_setup failed (seed {seed}, {players}P): {e}"))?;

    // Guard the INCOMING state so setup corruption is not misattributed to the
    // first move (the same discipline as the fuzz driver).
    if let Err(reason) = check_invariants(&state, rules) {
        return Err(format!(
            "corrupt starting state (seed {seed}, {players}P): {reason}"
        ));
    }

    let mut branching_by_phase: HashMap<TurnPhase, (u64, u64)> = HashMap::new();
    let mut moves_applied: u64 = 0;

    loop {
        if is_game_over(&state) {
            return Ok(HonestGameStats {
                seed,
                players,
                turns: state.turn_number,
                moves_applied,
                trigger: state.trigger_reason,
                result: final_result(&state, rules),
                branching_by_phase,
            });
        }
        if state.turn_number > HONEST_MAX_TURNS {
            return Err(format!(
                "non-termination: turn {} exceeded HONEST_MAX_TURNS (seed {seed}, {players}P)",
                state.turn_number
            ));
        }

        let seat = state.current_player;
        let legal = get_legal_moves(&state, rules);
        let entry = branching_by_phase.entry(state.turn_phase).or_insert((0, 0));
        entry.0 += legal.len() as u64;
        entry.1 += 1;
        if legal.is_empty() {
            return Err(format!(
                "dead end: no legal moves in a non-terminal state (seed {seed}, {players}P, turn {}, {:?})",
                state.turn_number, state.turn_phase
            ));
        }

        let view = observe(&state, seat)
            .map_err(|e| format!("observe failed for seat {} (seed {seed}): {e}", seat.0))?;
        // Plumbing pin: an agent must never be handed another seat's view.
        assert_eq!(view.viewer, state.current_player, "view/seat mismatch in run_honest_game");

        let chosen = agents[seat.0 as usize].choose_move(&view, &legal, rules);
        if !legal.contains(&chosen) {
            return Err(format!(
                "seat {} chose a move that is not in the legal list (seed {seed}, {players}P, turn {}, {:?}): {chosen:?}",
                seat.0, state.turn_number, state.turn_phase
            ));
        }

        state = apply_move_unchecked(&state, &chosen, rules).map_err(|e| {
            format!(
                "apply_move_unchecked rejected a legal move (seed {seed}, {players}P, seat {}): {e}",
                seat.0
            )
        })?;
        if let Err(reason) = check_invariants(&state, rules) {
            return Err(format!(
                "invariant violated after seat {}'s move (seed {seed}, {players}P): {reason}",
                seat.0
            ));
        }
        moves_applied += 1;
    }
}
```

```rust
//!
//! Two tiers, per the repo's gate policy: everything here runs per-edit at a

use rand::SeedableRng;

    "deck_removed_repartition",
    "hidden_order_swap",

fn keep_game(players: u8, seed: u64, rules: &Rules) -> GameState {
    let pending = new_game(GameConfig::for_player_count(players), rules, seed).unwrap();
    let choices: Vec<_> = (0..players).map(|_| StartingOrderChoice::Keep(0)).collect();

/// Variants of `state` that differ ONLY in what a seat cannot see. Sizes are
/// always preserved, so every variant is a state the seat could not rule out.
fn hidden_variants(state: &GameState, rng: &mut ChaCha8Rng) -> Vec<(&'static str, GameState)> {
    use rand::seq::SliceRandom;
    let mut out = Vec::new();

    let mut a = state.clone();
    a.order_deck.shuffle(rng);
    out.push(("deck_reshuffle", a));

    let mut b = state.clone();
    {
        let mut pool: Vec<_> = b.order_deck.iter().chain(b.orders_removed.iter()).copied().collect();
        pool.shuffle(rng);
        let d = b.order_deck.len();
        b.order_deck = pool[..d].to_vec();
        b.orders_removed = pool[d..].to_vec();
    }
    out.push(("deck_removed_repartition", b));

    let mut c = state.clone();
    {
        // Swap an opponent's unfulfilled starting order with a boxed card.
        let viewer = 0usize;
        let opp = c.players.iter().position(|p| {
            p.id.0 as usize != viewer
                && p.starting_order.is_some_and(|s| p.order_cards_in_hand.contains(&s))
        });
        if let (Some(oi), false) = (opp, c.orders_removed.is_empty()) {
            let old = c.players[oi].starting_order.unwrap();
            let bi = rng.gen_range(0..c.orders_removed.len());
            let new = c.orders_removed[bi];
            let hi = c.players[oi].order_cards_in_hand.iter().position(|x| *x == old).unwrap();
            c.players[oi].order_cards_in_hand[hi] = new;
            c.players[oi].starting_order = Some(new);
            c.orders_removed[bi] = old;
        }
    }
    out.push(("hidden_order_swap", c));

    let mut d = state.clone();
    d.tech_deck.shuffle(rng);
    out.push(("tech_permutation", d));

    let mut e = state.clone();
    e.config.setup_seed = e.config.setup_seed.wrapping_add(0x9E37_79B9_7F4A_7C15);
    out.push(("setup_seed_change", e));

    out
}

struct Tally {
    effective: HashMap<&'static str, usize>,
    deck_differing: usize,
    comparisons: usize,
}

/// The whole T1/T4/T5/T6 body, run at a given size. Returns the tally so both
/// tiers can assert their own floors.
fn run_honesty_sweep(
    counts: &[u8],
    seeds: &[u64],
    max_steps: Option<usize>,
    sample_every: usize,
    rules: &Rules,
) -> Tally {
    let mut tally = Tally {
        effective: FAMILIES.iter().map(|f| (*f, 0usize)).collect(),
        deck_differing: 0,
        comparisons: 0,
    };

    for &players in counts {
        for &seed in seeds {
            let mut state = keep_game(players, seed, rules);
            let mut rng = ChaCha8Rng::seed_from_u64(seed ^ 0xA5A5);
            let mut step = 0usize;

            while !is_game_over(&state) {
                if let Some(cap) = max_steps {
                    if step >= cap {
                        break;
                    }
                }
                let legal = get_legal_moves(&state, rules);
                assert!(!legal.is_empty(), "dead end at {players}P seed {seed} step {step}");

                if step % sample_every == 0 {
                    let seat = state.current_player;
                    let view = observe(&state, seat).unwrap();
                    let digest = view_digest(&view);

                    // T1: no hidden variation may move the view.
                    for (family, variant) in hidden_variants(&state, &mut rng) {
                        if variant != state {
                            *tally.effective.get_mut(family).unwrap() += 1;
                        }
                        let vv = observe(&variant, seat).unwrap();
                        assert_eq!(vv, view, "T1 {family}: hidden state leaked into the view");
                        assert_eq!(view_digest(&vv), digest, "T1 {family}: digest moved");

                        // T4: legality is view-measurable -- the variant's legal
                        // list must be identical, order included.
                        assert_eq!(
                            get_legal_moves(&variant, rules),
                            legal,
                            "T4 {family}: hidden state moved the legal list"
                        );
                    }

                    // T3/T5/T6 over sampled worlds.
                    let mut sampler = BeliefSampler::from_view(&view, rules, 77 + step as u64).unwrap();
                    for _ in 0..3 {
                        let world = sampler.sample();
                        tally.comparisons += 1;
                        if world.order_deck != state.order_deck {
                            tally.deck_differing += 1;
                        }

                        // T5: exact multiset partition + a valid state.
                        assert_multiset_partition(&world, rules);
                        assert!(check_invariants(&world, rules).is_ok(), "T5: sampled world invalid");
                        let mut canon = world.orders_removed.clone();
                        canon.sort_by_key(|c| c.0);
                        assert_eq!(world.orders_removed, canon, "T5: box must be canonical");

                        // T4 again, on the sample this time.
                        assert_eq!(
                            get_legal_moves(&world, rules),
                            legal,
                            "T4: a sampled world's legal list must equal the true one"
                        );

                        // T6a: round-trip.
                        assert_eq!(observe(&world, seat).unwrap(), view, "T6a: sample changed the view");

                        // T6b: public fidelity (Keep-shaped truth only -- every
                        // game in this corpus is Keep-shaped; the LIVE cells are
                        // covered by the live matrix test).
                        assert_public_fidelity(&world, &state);
                    }

                    // T3: determinism from (view, seed), independent of the truth.
                    let mut s1 = BeliefSampler::from_view(&view, rules, 5).unwrap();
                    let mut s2 = BeliefSampler::from_view(&view, rules, 5).unwrap();
                    assert_eq!(s1.sample(), s2.sample(), "T3: same (view, seed) must repeat");
                }

                let pick = legal[rng.gen_range(0..legal.len())].clone();
                state = apply_move_unchecked(&state, &pick, rules).unwrap();
                step += 1;
            }
        }
    }
    tally
}

fn assert_multiset_partition(world: &GameState, rules: &Rules) {
    let mut orders: Vec<u8> = Vec::new();
    orders.extend(world.order_deck.iter().map(|c| c.0));
    orders.extend(world.orders_removed.iter().map(|c| c.0));
    for slot in world.port_state.port_a.slots.iter().flatten() { orders.push(slot.0); }
    if let Some(b) = &world.port_state.port_b {
        for slot in b.slots.iter().flatten() { orders.push(slot.0); }
    }
    for p in &world.players {
        orders.extend(p.order_cards_in_hand.iter().map(|c| c.0));
        orders.extend(p.completed_orders.iter().map(|c| c.0));
    }
    orders.sort_unstable();
    let mut expect: Vec<u8> = rules.orders.iter_sorted_by_id().iter().map(|c| c.id.0).collect();
    expect.sort_unstable();
    assert_eq!(orders, expect, "order ids must partition exactly once each");

    let mut techs: Vec<u8> = world.tech_deck.iter().map(|c| c.0).collect();
    for slot in world.lab_state.lab_a.slots.iter().flatten() { techs.push(slot.0); }
    if let Some(b) = &world.lab_state.lab_b {
        for slot in b.slots.iter().flatten() { techs.push(slot.0); }
    }
    for p in &world.players { techs.extend(p.technologies.iter().map(|c| c.0)); }
    techs.sort_unstable();
    let mut expect_t: Vec<u8> = rules.techs.iter_sorted_by_id().iter().map(|c| c.id.0).collect();
    expect_t.sort_unstable();
    assert_eq!(techs, expect_t, "tech ids must partition exactly once each");
}

/// T6b: a sampled world must match the TRUE state everywhere a seat can see,
/// after canonicalizing the five hidden members away. Round-tripping the view
/// alone cannot catch a public field that BOTH sides drop or default.
fn assert_public_fidelity(world: &GameState, truth: &GameState) {
    let mut a = world.clone();
    let mut b = truth.clone();
    for s in [&mut a, &mut b] {
        s.config.setup_seed = 0;
        s.order_deck = vec![];
        s.tech_deck = vec![];
        s.orders_removed = vec![];
        for p in &mut s.players {
            if let Some(c) = p.starting_order {
                if p.order_cards_in_hand.contains(&c) {
                    let i = p.order_cards_in_hand.iter().position(|x| *x == c).unwrap();
                    p.order_cards_in_hand[i] = yokohama_core::OrderCardId(0);
                    p.starting_order = None;
                }
            }
        }
    }
    // Deck SIZES are public and must still match.
    assert_eq!(world.order_deck.len(), truth.order_deck.len(), "T6b: deck size");
    assert_eq!(world.tech_deck.len(), truth.tech_deck.len(), "T6b: tech deck size");
    assert_eq!(a, b, "T6b: a sampled world diverged from truth on PUBLIC state");
}
```

```rust
//!
//! WHY A CANARY: `TrivialHonestAgent`'s decision cannot possibly move under
//! T2's variants -- legality is view-measurable, so its inputs are invariant

use rand::SeedableRng;

fn live_game(players: u8, seed: u64, unknown_seats: &[u8], rules: &Rules) -> GameState {
    let pending = new_game(GameConfig::for_player_count(players), rules, seed).unwrap();
    let choices: Vec<_> = (0..players)
        .map(|i| if unknown_seats.contains(&i) { StartingOrderChoice::Unknown }
             else { StartingOrderChoice::Keep(0) })
        .collect();

/// Fold hidden content into a number. Any leak changes this.
fn hidden_fingerprint(s: &GameState) -> usize {
    s.order_deck.iter().map(|c| c.0 as usize).sum::<usize>() * 31
        + s.orders_removed.iter().map(|c| c.0 as usize).sum::<usize>() * 17
        + s.players.iter().filter_map(|p| p.starting_order).map(|c| c.0 as usize).sum::<usize>()
}

/// The canary's decision: index into `legal` by the hidden content of a world.
/// `cheat = None` uses an HONEST sample (blind to truth by construction);
/// `cheat = Some(truth)` simulates a sampler that peeked.
fn canary_pick(
    view: &PlayerView,
    legal: &[Move],
    rules: &Rules,
    sampler_seed: u64,
    cheat: Option<&GameState>,
) -> Move {
    let fp = match cheat {
        Some(truth) => hidden_fingerprint(truth),
        None => {
            let mut s = BeliefSampler::from_view(view, rules, sampler_seed).unwrap();
            hidden_fingerprint(&s.sample())
        }
    };
    legal[fp % legal.len()].clone()
}

fn variants(state: &GameState, rng: &mut ChaCha8Rng) -> Vec<GameState> {
    use rand::seq::SliceRandom;
    let mut out = Vec::new();
    let mut a = state.clone();
    a.order_deck.shuffle(rng);
    out.push(a);
    let mut b = state.clone();
    {
        let mut pool: Vec<_> = b.order_deck.iter().chain(b.orders_removed.iter()).copied().collect();
        pool.shuffle(rng);
        let d = b.order_deck.len();
        b.order_deck = pool[..d].to_vec();
        b.orders_removed = pool[d..].to_vec();
    }
    out.push(b);
    let mut c = state.clone();
    c.config.setup_seed = c.config.setup_seed.wrapping_add(12345);
    out.push(c);
    out
}

/// Walk a game, and at each sampled decision point return
/// (true_state, view, legal) for the acting seat.
fn decision_points(players: u8, seed: u64, max_steps: usize, rules: &Rules)
    -> Vec<(GameState, PlayerView, Vec<Move>)>
{
    let mut state = keep_game(players, seed, rules);
    let mut rng = ChaCha8Rng::seed_from_u64(seed ^ 0xBEEF);
    let mut out = Vec::new();
    let mut step = 0;
    while !is_game_over(&state) && step < max_steps {
        let legal = get_legal_moves(&state, rules);
        let view = observe(&state, state.current_player).unwrap();
        out.push((state.clone(), view, legal.clone()));
        let pick = legal[rng.gen_range(0..legal.len())].clone();
        state = apply_move_unchecked(&state, &pick, rules).unwrap();
        step += 1;
    }
    out
}

#[test]
fn t8c_live_matrix_reconciles_at_every_player_count() {
    let rules = Rules::standard();
    for players in [2u8, 3, 4] {
        let opponents: Vec<u8> = (1..players).collect();
        let configs: Vec<Vec<u8>> = vec![
            vec![],                        // no Unknown
            vec![opponents[0]],            // exactly one Unknown
            opponents.clone(),             // all opponents Unknown
        ];
        for unknown in configs {
            let state = live_game(players, 7, &unknown, &rules);
            let view = observe(&state, PlayerId(0)).unwrap();

            // Reconciliation identity.
            assert_eq!(
                view.unseen_orders(&rules).len(),
                view.order_deck_len + view.orders_removed_len + view.hidden_slot_count(),
                "{players}P unknown={unknown:?}: |U| must reconcile"
            );
            // Physical box size, independent of tracking shape.
            let expected_box = state.orders_removed.len() - unknown.len();
            assert_eq!(view.orders_removed_len, expected_box);

            // Sample, validate, round-trip.
            let mut s = BeliefSampler::from_view(&view, &rules, 3).unwrap();
            let w = s.sample();
            assert!(yokohama_core::check_invariants(&w, &rules).is_ok());
            assert_eq!(observe(&w, PlayerId(0)).unwrap(), view);

            // A live view equals the SIM view of the same physical truth.
            let sim = keep_game(players, 7, &rules);
            assert_eq!(observe(&sim, PlayerId(0)).unwrap(), view,
                       "{players}P unknown={unknown:?}: tracking shape is not seat-visible");
        }

        // Own-seat Unknown is refused at every player count.
        let own_hidden = live_game(players, 7, &[0], &rules);
        assert_eq!(observe(&own_hidden, PlayerId(0)), Err(ViewError::ViewerDealUnrecorded(PlayerId(0))));
    }
}

#[test]
fn t8e_the_unseen_pool_never_grows() {

    // peek effects and nothing returns a card to a deck (spec F12).

    let mut rng = ChaCha8Rng::seed_from_u64(5);

        assert!(now <= previous, "the unseen pool grew: {previous} -> {now}");
        previous = now;
    }
}

#[test]
fn t8f_red_team_the_public_board_still_recovers_a_small_setup_seed() {
    // EXECUTABLE RESIDUAL (spec §1-B / L7). `new_game` generates the board
    // from the setup seed BEFORE shuffling the deck, so the board -- which
    // every honest view must carry verbatim -- fingerprints the seed. Masking
    // the FIELD does not close the CHANNEL; seed entropy does. This test
    // exists so that limit can never be quietly forgotten.
    let rules = Rules::standard();
    let victim_seed = 77u64;
    let state = keep_game(2, victim_seed, &rules);
    let view = observe(&state, PlayerId(0)).unwrap();

    let mut recovered = None;
    for candidate in 0..2_000u64 {
        let pending = new_game(GameConfig::for_player_count(2), &rules, candidate).unwrap();
        if pending.state.board_layout == view.board_layout {
            recovered = Some(candidate);
            break;
        }
    }
    assert_eq!(
        recovered,
        Some(victim_seed),
        "if this ever FAILS to recover, the board/seed coupling changed -- re-read spec L7 \
         before assuming the residual is closed"
    );
}
```
