# The Tabletop Simulator extraction

This directory keeps the three repository-authored files of the Tabletop Simulator extraction of Yokohama (Steam Workshop 1840951801). The upload's sprite sheets, scans and two PDFs were extracted on 2025-12-07 by `parse_tts_mod.py`. `EXTRACTION_SUMMARY.md` is the record of that extraction and `asset_mapping.json` is its map. Both are kept as written, so the paths inside them are the paths they had. The tree has not carried the extracted files since 2026-10-23. A contributor who has them places the organized sheets at `tts-assets/organized/`, with the raw `images/` cache beside them at `tts-assets/images/` (both gitignored), and `docs/tools/mkcardart.py` reads them from there.
